# note-toolkit

note（note.com）のクリエイター向け、データ収集・分析の補助ツール集です。

> **非公式ツールです。** note株式会社とは関係がありません。
> noteの仕様が変わると、予告なく動かなくなることがあります。

## 収録ツール

| フォルダ | 内容 | 動作環境 |
|---|---|---|
| [`bookmarklet/`](bookmarklet/) | ダッシュボード（アクセス状況）の記事別データを Google スプレッドシートに保存するブックマークレット。全期間、期間指定、日次の連続取得に対応 | ブラウザ（noteにログイン中）＋ GAS |
| [`gas-automation/`](gas-automation/) | 自分の記事と質問箱のスプレッドシートへの自動保存、読者開拓の候補提案、トレンドと過去記事の照合（Discordに通知） | Google Apps Script |
| [`docs/`](docs/) | 開発メモ（note内部APIの調査記録） | － |

## 関連プロジェクト

- [Pirates of note（Pon）](https://github.com/jeanjeanjean-sama/pirates-of-note)：noteのアクセス数値を毎日記録するChrome拡張機能

## 利用上の注意

- 取得するのは**自分のアカウントのデータ**に限ってください。
- noteへのリクエストは、1秒以上の間隔をあけて送ります。間隔を短くするなどの改変はしないでください。
- AIが作るコメント案は参考です。コメントは必ず自分の言葉で、**手動で**投稿してください。自動投稿や大量投稿は、noteの規約でスパム行為にあたるおそれがあります。
- APIキー、Webhook URL、GASのURLは、スクリプトプロパティなどに保存してください。**コードに直接書いてコミットしないでください。**
