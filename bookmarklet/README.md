# note アクセス解析ブックマークレット v2

noteのダッシュボード（アクセス状況）の記事別データを Google スプレッドシートに保存するブックマークレットです。
**note公式とは無関係の非公式ツールです。**

## v1 からの変更点

| | v1 | v2 |
|---|---|---|
| 取得方式 | 画面の表を読み取り（「もっとみる」連打） | ダッシュボードと同じ GraphQL API を直接取得 |
| 全期間取得 | ページ移動＋2回クリック | 1回クリック、どのnoteページからでも可 |
| 期間指定 | URLから推測（失敗時は手入力） | ダイアログで指定（昨日／7日／28日／今月／先月のプリセット付き） |
| 日次ループ 9か月分 | 約2時間 | 約15分（1日あたり約3秒） |
| タブを裏にした場合 | 一時停止 | 止まらずに継続 |
| 途中停止 | 不可 | 「停止」ボタン。再実行すると続きから（重複は自動スキップ） |
| GASへの送信 | 1日ずつ | 10日分ずつまとめて送信 |

## セットアップ

1. **GASを更新**：既存の `doPost` と `normalizeDateValue_` を削除し、`gas/doPost_v2.gs` の中身を貼り付けます。`onOpen` と `crossCheckDailyAgainstCustom` はそのままです。
2. **再デプロイ**：「デプロイを管理」→ 既存のデプロイを編集 →「新しいバージョン」。この方法ならURLは変わりません。
3. **インストール**：`dist/install.html` をブラウザで開き、GASのURLを入力して、3つのボタンをブックマークバーへドラッグします。
   - 手動で入れる場合は、`dist/*.txt` の `YOUR_GAS_URL_HERE` を自分のURLに置き換えて、ブックマークのURL欄に貼り付けます。

※ ①全期間と②期間指定は旧GASのままでも動きます。③日次はGAS v2が必要です。

## 仕組みと安全性

- 認証：note にログイン中のブラウザの Cookie `note_gql_auth_token` を、noteとの通信にだけ使います。**GASを含む外部には送りません。**
- 負荷対策：note へのリクエストは1秒以上の間隔をあけます。エラー時は2秒・4秒・8秒・16秒と待ってから再試行します。
- 当日分は集計前のため、既定の終了日は「昨日」にしています。

## ビルド

```
npm install
npm run build   # src/ → dist/
```
